# User Scope

User scope compiles to user-level paths (`~/.claude/`, `~/.cursor/`) instead of the project directory, affecting the agent's global configuration.

See **[Personal Toolkit]({{< relref "personal-toolkit" >}})** for the full guide — assembling your global config from personal tools, internal resources, and community sources.

For the `--scope` flag details, see the **[CLI Reference]({{< relref "../reference/cli" >}})**.
